# To-DO-List-in-Java
⚙️ Features of our To-Do App: 1️⃣ Add new tasks. 2️⃣ Display all tasks with their current status. 3️⃣ Mark tasks as Done (✅) or Undone (❌). 4️⃣ Delete tasks securely. 5️⃣ Interactive UI with looping menus until exit.  💻 Tech Stack used:  Language: Java  Core Concepts: Classes, Objects, Encapsulation, Lists, Loops, Conditionals.
